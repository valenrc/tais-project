# Multilingual Persona Steering Benchmark
Notebooks & benchmark data for "cross-lingual transfer of personality traits in LLMs": my research project submission for the Technical AI Safety Project Sprint by BlueDot Impact - BAISH.

[Blogpost here](https://valenrc.substack.com/p/cross-lingual-transfer-of-personality)

## Enviroment
Google Workbench, Graphics Optimized: 1 NVIDIA L4 GPU, 4 vCPUs, 16GB RAM

Qwen-2.5-7B-Instruct, Qwen3-4B-Instruct-2507
